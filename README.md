# Power Electronics Converter Simulations | MATLAB & Simulink

This repository contains MATLAB/Simulink simulations of various **power electronics converters**, focusing on their operation, switching behavior, and output waveforms.

### 🔌 Converters Included

* Rectifiers
* Inverters
* AC–AC Voltage Regulators
* Cycloconverters
* Choppers (DC–DC Converters)
* Dual Converters

### 🛠️ Tools Used

* MATLAB
* Simulink

### 🎯 Objective

To understand and analyze the working principles and performance of power electronic converters through simulation.

### 📂 Repository Contents

Each folder contains the corresponding converter simulation files and related results, where available.
